Storage Manager Archive

개인용 Google Drive 파일 보관 및 검증 도구

Storage Manager Archive는 사용자가 명시적으로 선택한 파일을 자신의 Google Drive에 복사하고, 복사한 파일을 다시 다운로드해 무결성과 복원 가능성을 검증하는 로컬 도구입니다. 본 페이지는 Google OAuth 동의 화면에 연결되는 앱 설명 페이지입니다.

사용 기능

Google Drive API의 drive.file 권한으로 앱이 생성하거나 사용자가 허용한 파일에 접근합니다. 파일의 업로드, 다운로드, 크기 및 체크섬 검증, 파일 복원이 목적입니다. Gmail, 연락처 또는 캘린더 권한을 요청하지 않습니다.

현재 배포 범위

현재 기능은 소규모 합성 파일을 이용한 WSL 로컬 전송 시험 단계입니다. 암호화 전송 시험이 완료되었으며, 운영 서버 자동 보관과 원본 제거는 활성화되지 않았습니다. 원본 파일을 자동 삭제하거나 보관 파일을 공개 공유하지 않습니다.

개인정보

OAuth 토큰과 보관용 암호화 설정은 소유자가 관리하는 접근 제한된 로컬 설정 파일에 저장됩니다. 보관 자료는 소유자 자신의 Google Drive에 저장되며, 이 공개 웹사이트는 로그인 정보를 수집하지 않습니다.
